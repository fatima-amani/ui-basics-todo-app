# UI Basics Todo App

A simple and clean todo list application built to demonstrate fundamental UI development skills and basic web technologies.

## 🌐 Live Demo

**[View Live Application](https://fatima-amani.github.io/ui-basics-todo-app/)**

## 📋 About

This project is a straightforward todo list application that allows users to manage their daily tasks. It's designed as a learning project to practice core web development concepts and user interface basics.

## ✨ Features

- Add new task
- Delete tasks
- Change status of a task
- Clean and intuitive user interface
- Responsive design
- Deployed on GitHub Pages for easy access

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages (for deployment)

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Text editor or IDE (optional, for development)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/fatima-amani/ui-basics-todo-app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd ui-basics-todo-app
   ```

3. Open `index.html` in your web browser or use a local development server.
